# Schumann / WWLLN research state — 2026-08-24

This directory preserves the closed v12 WWLLN/coherency result and the subsequent preregistered transient/common-view v1 experiment.

## Scientific progression

1. **v11**: integrity architecture and measured H1-L1 shared Schumann-band field; static-lag stability failed.
2. **v12 / Chain7**: contemporaneous 30-minute WWLLN energy maps did not improve prediction of H1-L1 complex coherency over stationary alternatives. LOO and radius checks are post-result audits only.
3. **Transient/common-view v1**: time-only association of independently detected H1/L1 transients to named WWLLN strokes did not beat a 1000-shift null (`p_emp = 0.4216`).

## Current boundary

The project has not demonstrated a satellite-free positioning or precision time-transfer system. The presently supported statements are narrower:

- the shared field exists;
- the 30-minute WWLLN energy map is not a validated source ephemeris for the measured complex coherency on the tested interval;
- time-only transient association at 128 Hz is not sufficient to establish common-view event identity;
- polarization/bearing plus waveform identity remains an untested follow-on.

## Data handling

The raw WWLLN stroke file is **not** included because it is copyrighted by the University of Washington and was provided under non-redistribution terms. Public-safe derived artifacts use hashed/local stroke identifiers rather than reproducing raw catalog rows.
